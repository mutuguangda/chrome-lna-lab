Chrome LNA 对照实验

保持 Local Network Access Checks 为 Default 或 Enabled。关闭系统代理及 TUN，按顺序在同一个浏览器环境测试。

allow 是权限委托，仍受用户授权和父页面策略约束。当前为公网 HTTPS 静态实验。默认 iframe 与父页面同源，可验证公网到内网的 LNA。跨域 iframe 委托需填写另一公网来源的 frame.html 完整地址。Pages 不提供后端网关或自定义 Permissions-Policy。

切换场景会销毁旧 iframe，不会自动请求接口。请在 iframe 内点击请求。
